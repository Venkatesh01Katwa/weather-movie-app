# Weather and Movie Finder

A beginner-friendly JavaScript project featuring two useful web applications: a Weather App and a Movie Search App.

## Features

### Weather App
- Search for weather by city name.
- View the current temperature and weather conditions.
- Check humidity and wind speed.
- Handle invalid city names and API errors.
- Responsive layout for different screen sizes.

### Movie Search App
- Search for movies by title.
- View movie posters, release years, and IMDb ratings when available.
- Display helpful messages when no movies are found.
- Handle missing posters and unavailable ratings.
- Load movie data dynamically without refreshing the page.

## Technologies Used

- HTML5
- CSS3
- JavaScript (ES6+)
- Fetch API and async/await
- Open-Meteo API for weather data
- OMDb API for movie information
- JavaScript modules

## How to Run the Project

1. Download or clone this repository.
2. Open the project folder in Visual Studio Code.
3. Install or enable the Live Server extension.
4. Open `weather/index.html` with Live Server to use the Weather App.
5. Open `movies/index.html` with Live Server to use the Movie Search App.

## Project Structure

- `weather/` — Weather application files.
- `movies/` — Movie search application files, including the movie utility module.
- `README.md` — Project documentation.

## APIs Used

- Open-Meteo: https://open-meteo.com/
- OMDb API: https://www.omdbapi.com/
The Weather App uses Open-Meteo's public services. The Movie Search App requires a valid OMDb API key.

## Learning Outcomes

This project demonstrates DOM manipulation, event handling, form processing, API integration, asynchronous JavaScript, error handling, JSON data processing, and JavaScript modules.
